Wren BASIC Quick Reference

The language of the 8-bit OLED Thing: event handlers, 16-bit integers and a 64 x 32 screen
16-bit signed integers 64 x 32 OLED, 4 fonts 3,456 B program store keywords in any case

Program shape

No main loop and no line numbers. At the top level only these may appear; every other statement lives inside a handler, SUB or FUNCTION.

CONST LIMIT = 200          ' a named constant
DIM count, row(8) AS BYTE  ' globals and arrays

ON event ... END ON         ' runs when the event happens
SUB Name(a, b) ... END SUB
FUNCTION Name(a) ... END FUNCTION

One statement per line, or several separated by :. Comments start with ' or REM.

Events

HandlerRunsVALUE
ON STARTOnce, after reset0
ON CHANGEb0-b7 differ from last time (checked every ms); once after STARTb0-b7
ON PINSAny of PA1-PA3, PD2, PD3 changes (debounced 20 ms); once after STARTb0-b7
ON LATCH pinAn edge on the pin; b0-b7 read in the interruptb0-b7 at the edge
ON PRESS pinThe pin goes low (debounced 20 ms)b0-b7
ON RELEASE pinThe pin goes high (debounced 20 ms)b0-b7
ON EVERY n [MS]Every n ms, n a constant 1-65535; up to 40
ON LATCH pin [FALLING|RISING|BOTH] [WHILE pin LOW|HIGH]
ON LATCH PD3 RISING WHILE PD2 LOW   ' clock and /WE

LATCH is falling-edge unless stated; the WHILE pin must be a different pin. Pins: PA1, PA2, PA3, PD2, PD3. Handlers run one at a time, to completion; events wait in a queue, and LOST counts any dropped.

Control flow

IF c THEN                 IF c THEN stmt [ELSE stmt]
  ...                     WHILE c
ELSEIF c THEN               ...
  ...                     WEND
ELSE                      FOR i = a TO b [STEP s]
  ...                       ...
END IF                    NEXT [i]
EXIT FOR|WHILE|SUB|FUNCTION|ON
[LET] x = exprAssignment; a(i) = expr for an element
Name a, bCall a SUB; also CALL Name(a, b) or Name(a, b)
RETURN [expr]Leave a SUB, or a FUNCTION with its value
STEP sMust be a constant, not 0; it may be negative

A FUNCTION with no parameters is used without brackets: IF DiceMode THEN.

Example: two latched rows

' Two rows: PD3 latches the top one, PD2 the bottom one
DIM top, bottom

ON LATCH PD3          SUB Draw
  top = VALUE           CLS
  Draw                  HEX 0, 0, top, 2, LARGE
END ON                  HEX 0, 16, bottom, 2, LARGE
                        BITS 30, 2, 32, 12, top
ON LATCH PD2            BITS 30, 18, 32, 12, bottom
  bottom = VALUE        SHOW
  Draw                END SUB
END ON

Values and variables

DIM x, y16-bit signed integers, -32768 to 32767, starting at 0
DIM a(n)Array of n integers: a(0) to a(n-1)
DIM a(n) AS BYTEArray of n bytes, 0-255 (AS INTEGER is the default)
CONST N = 10Named constant, folded at compile time

Top-level DIMs are globals; a DIM inside a SUB, FUNCTION or handler makes locals (0 on entry). Arrays are global only. Parameters are passed by value.

Numbers: 123, &H1F or $1F, &B101, up to 65535. Strings only as TEXT literals.

Any non-zero value is true in IF and WHILE. AND is bitwise: test a bit with (v AND 4) <> 0.

On a real Thing

Tools → Firmware…, Connect, Install kernel once: it installs the board's kernel. Then Debug → Target → Thing on the programmer: F5 debugs there (two breakpoints), Ctrl+F5 runs; uploads only when changed.

LED Thing (Board → LED Thing): LEDS v lights bn's LED for each bit n; mode pins M0 PA3, M1 PA2, M2 PA1; no display, fonts or ANALOG. A fault lights b7, n in b0-b6.

The screen

64 x 32 pixels. x runs 0-63 left to right, y 0-31 top to bottom; (0, 0) is the top left. Drawing off the edge is clipped.

Draw into the frame buffer, then SHOW. A handler usually starts with CLS and ends with SHOW.

Faults: ERR n

1Value stack full5Division by zero
2Value stack empty6Bad opcode
3Call stack full7Jump outside the program
4Array index out of range

A fault stops the program and shows ERR n and the program address on the OLED. The kernel keeps running, so a new program can always be uploaded.
